# Application fonts

IBM Plex Sans, Regular (400), Medium (500), SemiBold (600) and Bold (700), downloaded from the official IBM/plex repository on 22 October 2026.

Source: https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/woff2

The bundled OFL.txt contains the original license. Fonts are served locally, so the application does not request Google Fonts or another font CDN.
